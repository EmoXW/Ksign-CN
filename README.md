# Ksign-CN

[![上游发布版本](https://img.shields.io/github/v/release/nyasami/ksign?style=for-the-badge&color=3c94fc)](https://github.com/nyasami/ksign/releases/latest)
[![上游累计下载量](https://img.shields.io/github/downloads/nyasami/ksign/total?style=for-the-badge&color=6bc563)](https://github.com/nyasami/ksign/releases)

又一款 iOS 应用签名工具。你有没有想过，如果将 Feather 与 Esign 结合起来，会是什么样子？

本仓库在原版 [Ksign](https://github.com/Nyasami/Ksign) 的基础上添加了简体中文支持，涵盖导航、设置、签名、证书、下载和文件管理等界面。下方的版本下载、社区链接和 Star 历史均属于上游项目。

## 为什么开发 Ksign？

Esign 停止服务后，用户开始转向其他签名工具。但 Esign 曾是社区中非常重要的一部分，因此原作者以 Feather 为基础，尝试尽可能还原 Esign 的使用体验，让用户更容易上手，减少在不同应用之间切换，使侧载过程更加顺畅。

另一个原因是，这款应用最初专为 Khoindvn 分享证书而开发，希望让更多人无需购买证书，也能体验应用侧载。

## 获取帮助

本仓库中文翻译相关的问题，请在 [Ksign-CN 的 Issues](https://github.com/EmoXW/Ksign-CN/issues) 中反馈。

原版应用的问题或功能建议，可以提交至[上游问题反馈页面](https://github.com/Nyasami/Ksign-public/issues)。

你也可以加入 [Ksign Discord 社区](https://discord.gg/sfbZfQzVdQ)，与其他用户交流。

## 下载与使用

如需使用本仓库添加的简体中文界面，请编译本仓库源码并安装，再将系统或 App 的语言设置为简体中文。

原版 IPA 可前往[上游发布页面](https://github.com/Nyasami/Ksign-public/releases)下载。该链接指向上游原版，不代表本仓库的中文构建。
